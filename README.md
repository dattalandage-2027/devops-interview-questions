# DevOps Interview Questions

A tool-based collection of DevOps, cloud, platform engineering, and SRE interview questions.

## Question areas

| Area | Topics |
| --- | --- |
| Linux | Processes, permissions, networking, storage, systemd, troubleshooting |
| Git and GitHub | Branching, merge strategies, pull requests, hooks, recovery |
| Jenkins | Pipelines, agents, shared libraries, credentials, troubleshooting |
| Docker | Images, containers, networking, storage, security, optimization |
| Kubernetes | Workloads, services, scheduling, RBAC, storage, debugging |
| Terraform | State, modules, providers, lifecycle, workspaces, drift |
| Ansible | Inventory, playbooks, roles, variables, vault, idempotency |
| Cloud | IAM, networking, compute, storage, databases, high availability |
| GitOps | Reconciliation, promotion, rollback, secrets, Argo CD and Flux |
| Observability | Metrics, logs, traces, alerting, incident response |
| Security | Least privilege, supply chain, secrets, scanning, compliance |
| SRE | SLIs, SLOs, error budgets, capacity, resilience, postmortems |

## Question format

Each tool document should include:

1. Beginner questions and concise answers
2. Intermediate implementation questions
3. Advanced troubleshooting scenarios
4. Hands-on exercises
5. Architecture and behavioral questions

## Contribution rules

- Prefer practical questions over trivia.
- Explain why an answer is correct.
- Include commands or examples only when they improve understanding.
- Never include real credentials, private infrastructure details, or confidential interview material.
